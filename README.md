# Laudos Uniware

Modelos de laudos com cálculo enviados pela equipe, sem login, identificados pelo nome declarado no envio.

Catálogo e envio: https://uniware-laudos.brandonuniware.chatgpt.site

O modelo aparece imediatamente no catálogo online. Este repositório mantém uma cópia automática por GitHub Actions, com execução agendada a cada 15 minutos (o GitHub pode atrasar o início).

Arquivos de qualquer formato, inclusive sem extensão, até 512 KB. Codificação e conteúdo são preservados byte a byte. Os modelos são copiados sem executar cálculos, scripts ou fórmulas. Envie somente modelos, sem dados de pacientes.

Não há credencial do GitHub no utilitário nem na hospedagem. A sincronização usa apenas o `GITHUB_TOKEN` temporário do próprio workflow, com permissão de escrita neste repositório.
